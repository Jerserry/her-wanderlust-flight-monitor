✦ Airline watch
单程 vs 来回怎么比较？

系统会使用相同出发日期分别查询单程和来回。来回预算沿用航线管理中的目标预算；单程价格先作为独立参考，不直接套用来回预算。系统不会预先限定航空公司名单；会收集 Google Flights 本次搜索实际返回的航空公司及航班组合。若某家航空公司没有出现在结果中，不代表该航线没有该航空公司航班。

如何新增真正的自动监控航线？

目前航线由 GitHub 的 config/routes.json 控制。修改该文件并提交后，系统会按排程追踪新航线。此网页不会把 API 密钥暴露在浏览器，也不会假装本地新增的航线已开始监控。

预算状态

通知规则

系统每天检查四次（马来西亚时间 00:00、06:00、12:00、18:00）。达到预算、刷新预算内历史最低价，或价格较上次下降至少 5% 时会发送 Telegram 通知。若没有配置 Telegram Secrets，价格仍会保存到历史记录，但不会发送消息。
